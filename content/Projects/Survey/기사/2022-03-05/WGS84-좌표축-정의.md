## 1. WGS84 좌표계란?

### WGS84의 정의 🌍

**WGS84 (World Geodetic System 1984)**
- GPS 위성측량의 **기준 좌표계**
- 전 세계적으로 사용되는 **지심좌표계** (Geocentric Coordinate System)
- 1984년에 미국 국방부에서 제정

```bash
┌────────────────────────────────────────┐
│  WGS84 = GPS의 언어                    │
│  - GPS 위성이 사용하는 좌표계          │
│  - 지구 중심을 원점으로 함             │
│  - 3차원 직교좌표계 (X, Y, Z)         │
└────────────────────────────────────────┘
```
> 🔍 **이미지 검색어**: `WGS84 coordinate system diagram` or `GPS geocentric coordinate system`

### WGS84가 만들어진 배경

#### 왜 WGS84가 필요했는가?

1️⃣ **GPS 위성의 등장**
```bash
🛰️ GPS 위성 (지구 궤도)
   ↓ 신호
   ↓
   📍 지구상의 점
   
문제: 위성과 지상의 위치를 
      같은 기준으로 표현해야 함!
```
> 🔍 **이미지 검색어**: `GPS satellite signal to ground station` or `satellite positioning system diagram`

2️⃣ **기존 좌표계의 한계**
- 각 나라마다 다른 측지계 사용
- 지역 측지계는 지구 중심과 일치하지 않음
- GPS는 전 지구적 기준이 필요

3️⃣ **해결책: WGS84**
```bash
┌─────────────────────────────────────┐
│ WGS84의 특징                        │
│ ✓ 지구 중심이 원점                  │
│ ✓ 전 세계 공통 기준                 │
│ ✓ 중력장 데이터 반영                │
│ ✓ 정밀한 지구 타원체 정의           │
└─────────────────────────────────────┘
```
> 🔍 **이미지 검색어**: `WGS84 features characteristics` or `WGS84 global reference system`

### WGS84 좌표계의 구성 요소

#### 1) 원점 (Origin)

**지구의 질량중심 (Geocenter)**
```bash
        북극
         ●
        /|\
       / | \
      /  |  \
     /   ●   \ ← 지구 질량중심 (원점)
    /    |    \
   /     |     \
  ●━━━━━━━━━━━● 적도
  
  원점 = 지구의 무게중심
```
> 🔍 **이미지 검색어**: `Earth geocenter mass center` or `geocentric origin diagram`

- 위치: 지구의 질량중심
- 정확도: 수 cm 이내로 결정
- 근거: 전 세계 측정 데이터

#### 2) 좌표축의 정의

**3차원 직교좌표계 (X, Y, Z)**

```bash
        Z축 (북극 방향)
         ↑
         |
         |
         ●━━━━━━━━→ X축 (본초자오선, 그리니치)
        /|
       / |
      /  |
     ↙   |
   Y축   |
(서쪽 90°)
```
> 🔍 **이미지 검색어**: `WGS84 XYZ axes cartesian coordinate` or `ECEF coordinate system 3D axes`

##### ① X축의 정의

**정의**: 본초자오선(그리니치)과 적도면의 교차선

```bash
       북극
        |
        |
    ────●──── 적도면
   /    |    \
  /     |     \
 /  그리니치  \
●━━━━━━━━━━━━●
↑
X축 (경도 0°, 위도 0°)
```
> 🔍 **이미지 검색어**: `prime meridian equatorial plane X axis` or `Greenwich meridian equator intersection`

**핵심 포인트**:
- **본초자오선**: 국제시보국(BIH)에서 정의
- **적도면과의 교점**: 경도 0°, 위도 0° 지점
- **방향**: 아프리카 서해안 방향

##### ② Y축의 정의

**정의**: X축과 Z축에 직교하는 축 (동쪽으로 90°)

```bash
       북극 (Z축)
        |
        |
        ●━━━━━━━━→ X축 (경도 0°)
       /|
      / |
     /  |
    ↙   
  Y축 (경도 90° 동쪽)
  
  예: 인도양 방향
```
> 🔍 **이미지 검색어**: `Y axis 90 degrees east longitude` or `right-hand coordinate system XYZ earth`

**핵심 포인트**:
- **X축에서 동쪽으로 90°** 회전
- **적도면 위**에 위치
- Z축과도 직교 (오른손 법칙)

🔴 **주의**: 문제에서 "서쪽으로 90°"라고 하면 **틀림**!

##### ③ Z축의 정의

**정의**: 1984년 국제시보국(BIH)에서 채택한 평균극축(CTP)과 평행

```bash
    북극점
      ●  ← CTP (Conventional Terrestrial Pole)
      ↑
      | Z축 (평균극축과 평행)
      |
      ●  지구 중심 (원점)
      |
      ↓
      ●
    남극점
```
> 🔍 **이미지 검색어**: `CTP conventional terrestrial pole Z axis` or `Earth rotation axis polar motion`

**CTP (Conventional Terrestrial Pole)란?**
- 지구 자전축의 평균 위치
- 실제 극축은 미세하게 흔들림 (극운동)
- 여러 해 동안의 평균값을 사용

**핵심 포인트**:
- **1984년 BIH**에서 정의한 극축
- 지구의 **자전축 방향**
- 북극 방향이 **양(+)의 방향**

#### 3) 기준 타원체

**WGS84 타원체의 매개변수**

| 매개변수 | 값 | 의미 |
|---------|-----|------|
| **장반경 (a)** | 6,378,137 m | 적도 반지름 |
| **편평률 (f)** | 1/298.257223563 | 찌그러진 정도 |
| **단반경 (b)** | 6,356,752.3142 m | 극 반지름 |

```bash
     북극
      ●  ← b = 6,356,752 m
     /|\
    / | \
   /  |  \
  /   ●   \ 지구 중심
 /    |    \
●━━━━━━━━━━● 적도
←─────────→
a = 6,378,137 m

편평률 f = (a-b)/a ≈ 1/298.26
```
> 🔍 **이미지 검색어**: `WGS84 ellipsoid parameters semi-major axis` or `Earth ellipsoid flattening diagram`

**왜 타원체인가?**
- 지구는 완전한 구가 아님
- 자전에 의해 적도 방향으로 부풀어 오름
- 극 반지름 < 적도 반지름

#### 4) 중력장 모델

**EGM (Earth Gravitational Model)**

```bash
지구 중력장 측정
    ↓
┌───────────────────────┐
│ • 인공위성 궤도 분석   │
│ • 지상 중력 측정      │
│ • 해양 중력 측정      │
└───────────────────────┘
    ↓
중력장 모델 (EGM)
    ↓
WGS84에 반영
```
> 🔍 **이미지 검색어**: `EGM Earth Gravitational Model` or `geoid gravity field measurement`

**왜 중력장이 중요한가?**
- GPS 위성의 궤도 계산에 필수
- 높이 결정의 기준 (지오이드)
- 정밀한 위치 결정

### WGS84 좌표계의 특징

#### 지심좌표계 (Geocentric)

```bash
┌────────────────────────────────────┐
│ 지심좌표계 vs 지역 측지계          │
└────────────────────────────────────┘

지심좌표계 (WGS84)     지역 측지계 (예: Bessel)
       ●  원점              ●  원점 (지역 최적화)
      /|\                  /|\
     / | \                / 📍 \
    /  📍 \              /  |  \
   /___|___\            /___|___\
      지구                 지구
      
✓ 지구 중심 일치        ✗ 지구 중심 불일치
✓ 전 세계 공통          ✗ 지역마다 다름
✓ GPS와 호환            ✗ 변환 필요
```
> 🔍 **이미지 검색어**: `geocentric vs local geodetic datum` or `WGS84 vs regional coordinate system`

#### 전 지구적 기준

| 특징 | 설명 |
|------|------|
| **통일성** | 전 세계 동일한 기준 사용 |
| **호환성** | 모든 GPS 기기가 동일 결과 |
| **정확성** | 전 지구 데이터로 최적화 |
| **표준성** | 국제 표준 좌표계 |

#### 데이터 기반

**WGS84는 다음 데이터를 기반으로 만들어짐:**

1. **위성 측량 데이터**
   - GPS, VLBI (초장기선 간섭계)
   - 위성 레이저 측거 (SLR)

2. **중력장 측정**
   - 지상 중력 측정
   - 인공위성 중력 측정
   - GRACE, GOCE 위성 데이터

3. **지구 형상 데이터**
   - 위성 고도계
   - 전 세계 측지 관측망

### WGS84의 실제 사용

#### GPS 측량에서의 역할

```bash
GPS 위성 (WGS84 좌표)
  🛰️  🛰️  🛰️  🛰️
   \   |   |   /
    \  |   |  /
     \ |   | /
      \|   |/
       📍 수신기
       
수신기가 계산하는 좌표
→ WGS84 좌표 (X, Y, Z)
  또는 (φ, λ, h)
  
φ: 위도, λ: 경도, h: 타원체고
```
> 🔍 **이미지 검색어**: `GPS trilateration satellites receiver` or `GPS positioning principle diagram`

#### 좌표 변환

**WGS84에서 다른 좌표계로**

```bash
WGS84 좌표 (GPS 측정)
    ↓
변환 파라미터 적용
(ΔX, ΔY, ΔZ, 회전, 축척)
    ↓
지역 좌표계
(예: 한국 TM, UTMK)
```
> 🔍 **이미지 검색어**: `datum transformation parameters` or `coordinate system conversion 7-parameter`

**변환이 필요한 이유:**
- 기존 지도는 지역 측지계 사용
- 국가마다 고유 좌표계 존재
- 토목/건설은 지역 좌표계 사용

### WGS84의 개정

**WGS84는 계속 업데이트됩니다!**

| 버전 | 연도 | 주요 변경 |
|------|------|----------|
| WGS84(Original) | 1984 | 최초 제정 |
| WGS84(G730) | 1994 | GPS 관측으로 정밀화 |
| WGS84(G873) | 1997 | ITRF와 정합 |
| WGS84(G1150) | 2002 | 정밀도 향상 |
| WGS84(G1674) | 2012 | 최신 중력장 반영 |
| WGS84(G1762) | 2013 | 현재 사용 |
| WGS84(G2139) | 2021 | ITRF2014 기반 |

**왜 업데이트하는가?**
- 더 정밀한 측정 데이터 확보
- 지구 물리학적 변화 반영
- 판구조 운동 (매년 수 cm 이동)
- ITRF와의 호환성 유지

### 핵심 요약

#### WGS84 좌표축 정의 (시험 출제!)

```bash
┌─────────────────────────────────────┐
│ ✓ X축: 본초자오선 × 적도면           │
│   (경도 0°, 위도 0°)                │
│                                     │
│ ✓ Y축: X축에서 동쪽으로 90° 🔴       │
│   (경도 90°E, 위도 0°)              │
│   ※ "서쪽"이라고 하면 틀림!          │
│                                     │
│ ✓ Z축: 평균극축(CTP)과 평행          │
│   (북극 방향)                       │
└─────────────────────────────────────┘
```
> 🔍 **이미지 검색어**: `WGS84 axes definition summary` or `ECEF coordinate axes orientation`

#### 암기 포인트

1. **기반**: 전 세계 중력장 + 지구 형상 데이터
2. **원점**: 지구 질량중심 (Geocenter)
3. **X축**: 본초자오선 × 적도면
4. **Y축**: 동쪽으로 90° (오른손 법칙)
5. **Z축**: 1984년 BIH의 평균극축(CTP)과 평행
6. **타원체**: a=6,378,137m, f=1/298.257
7. **용도**: GPS 위성측량의 기준

#### 자주 나오는 오류 🚨

| 틀린 설명 | 올바른 설명 |
|---------|-----------|
| Y축: 서쪽으로 90° ❌ | Y축: **동쪽으로 90°** ✓ |
| Z축: 북극점과 일치 ❌ | Z축: **평균극축과 평행** ✓ |
| 원점: 지표면 ❌ | 원점: **지구 질량중심** ✓ |
| 구형 지구 ❌ | **타원체** (편평률 1/298.26) ✓ |

## 2. 연습 문제

15.	GPS 측량의 기준좌표계인 WGS84에 대한 설명으로 옳지 않은 것은?(정답률:64%)
     
     1.	전 세계적으로 측정해온 지구의 중력장과 지구 모양을 근거로 해서 만들어진 좌표계이다.
     2.	X축은 국제시보국(BIH)에서 정의한 본초자오선과 평행한 평면이 지구 적도면과 교차하는 선이다.
     3.	Y축은 X축과 Z축이 이루는 평면에 서쪽으로 수직인 방향(서쪽으로 90°)으로 정의된다.
     4.	Z축은 1984년 국제시보국(BIH)에서 채택한 평균극축(CTP)과 평행하다.

**정답**: 3번

**해설**:

### 각 선택지 분석

#### ✅ 1번: 올바른 설명

**"전 세계적으로 측정해온 지구의 중력장과 지구 모양을 근거로 해서 만들어진 좌표계이다."**

```bash
WGS84 제작 과정
    ↓
┌───────────────────────┐
│ • 전 세계 중력 측정    │
│ • 위성 궤도 분석      │
│ • 지구 형상 관측      │
│ • VLBI, SLR 데이터    │
└───────────────────────┘
    ↓
EGM (중력장 모델)
WGS84 타원체
    ↓
WGS84 좌표계 완성
```
> 🔍 **이미지 검색어**: `WGS84 development process geodetic survey` or `global geodetic observation network`

**근거**:
- 수십 년간의 전 지구적 측정 데이터 사용
- 중력장 모델 (EGM) 반영
- 지구 형상 (타원체 매개변수) 결정
- 따라서 **정확한 설명** ✓

---

#### ✅ 2번: 올바른 설명

**"X축은 국제시보국(BIH)에서 정의한 본초자오선과 평행한 평면이 지구 적도면과 교차하는 선이다."**

```bash
        북극
         |
         |
    ─────●───── 적도면
    /    |    \
   / 본초자오선 \
  /  (BIH 정의) \
 ●━━━━━━━━━━━━●
 ↑
X축 (경도 0°, 위도 0°)
```
> 🔍 **이미지 검색어**: `BIH prime meridian X axis definition` or `Greenwich meridian equatorial plane`

**해석**:
- **본초자오선**: BIH에서 정의한 경도 0° 자오선
- **평행한 평면**: 본초자오선을 포함하는 평면
- **적도면과 교차하는 선**: 이 평면과 적도가 만나는 선
- 결과: **X축의 정확한 정의** ✓

#### ❌ 3번: 틀린 설명 (정답!)

**"Y축은 X축과 Z축이 이루는 평면에 서쪽으로 수직인 방향(서쪽으로 90°)으로 정의된다."**

```bash
❌ 틀린 설명 (문제에서 말하는 것)
        Z
        |
        |
        ●━━━━━━━━→ X축
       /|
      / |
     ↙  |
   Y축? (서쪽 90°) ← 틀림!
   
✓ 올바른 정의
        Z
        |
        |
        ●━━━━━━━━→ X축 (경도 0°)
       /|
      / |
     ↘  |
    Y축 (동쪽 90°) ← 맞음!
```
> 🔍 **이미지 검색어**: `right-hand rule coordinate system` or `Y axis east direction 90 degrees`

**왜 틀렸는가?**

1️⃣ **방향이 반대**
- 문제: "서쪽으로 90°" ❌
- 정답: "**동쪽으로 90°**" ✓

2️⃣ **오른손 법칙 위반**

```bash
오른손 좌표계 (WGS84)
    
  검지 → X축 (경도 0°)
  중지 → Y축 (경도 90° 동쪽) ✓
  엄지 → Z축 (북극)
  
만약 Y축이 서쪽이면?
→ 왼손 좌표계가 됨 (잘못된 체계)
```
> 🔍 **이미지 검색어**: `right-hand coordinate system fingers` or `right-hand rule 3D coordinates`

3️⃣ **실제 위치**

| 축 | 방향 | 경도 | 지역 |
|----|------|------|------|
| X축 | 본초자오선 | 0° | 아프리카 서해안 |
| **Y축** | **동쪽 90°** | **90°E** | **인도양** ✓ |
| Y축(오답) | 서쪽 90° ❌ | 90°W | 북미 |

**따라서 3번은 틀린 설명입니다!** 🔴
