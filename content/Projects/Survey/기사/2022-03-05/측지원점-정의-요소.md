## 1. 측지원점(Geodetic Datum)이란?

### 측지원점의 정의 🎯

**측지원점(測地原點, Geodetic Datum)** 은 국가의 모든 측량의 기준이 되는 점입니다.

```bash
       측지원점 📍
          ↓
  ┌───────┼───────┐
  │       │       │
전국 측량의 기준점들
  │       │       │
모든 좌표의 출발점
```
> 🔍 **이미지 검색어**: `geodetic control network` or `survey control points` or `geodetic datum concept`

**왜 필요한가?**
- 모든 측량은 **하나의 통일된 기준**이 필요
- 국가 지도 제작의 **시작점**
- GPS 좌표를 지역 좌표계로 변환하는 **기준**

**대한민국의 측지원점:**
- 위치: 수원시 영통구 원천동 (국토지리정보원 내)
- 좌표계: WGS84 (2002년 이후), 이전에는 Bessel 1841 타원체 사용

## 2. 측지원점을 정의하는 요소

측지원점을 완벽하게 정의하려면 **기하학적, 위치적, 방향적** 요소가 모두 필요합니다.

### 필수 요소 목록

#### 1️⃣ 기하학적 요소 (타원체 정의)

측지원점은 **지구를 어떤 타원체로 근사할 것인가**를 정의해야 합니다.

```bash
        북극 ●
         /│\
        / │ \
       /  │b \  ← 단반경
      /   │   \
    ━━━━━●━━━━━ 적도
    ←──── a ────→ 장반경
```
> 🔍 **이미지 검색어**: `reference ellipsoid diagram` or `earth ellipsoid axes` or `ellipsoid semi-major minor axis`

**필요한 요소:**

**a. 타원체의 장반경 (Semi-major Axis)** 🔴
```bash
기호: a
의미: 지구 적도 반경
WGS84: a = 6,378,137 m
```
- 지구 타원체의 **가장 긴 반지름**
- 적도를 따라 측정
- **측지원점 정의에 필수!**

**b. 타원체의 편평률 (Flattening)**
```bash
기호: f
의미: 지구가 얼마나 찌그러졌는가
공식: f = (a - b) / a
WGS84: f = 1/298.257223563
```
- 장반경과 단반경의 차이
- 지구의 찌그러진 정도
- **측지원점 정의에 필수!**

💡 **장반경 + 편평률 → 타원체 완전 정의**

#### 2️⃣ 위치 요소 (원점의 위치)

**c. 원점의 경도 (Longitude)** 🔴
```bash
           북극
            |
      ━━━━●━━━━━ 본초자오선 (0°)
    서경  |  동경
         📍
    원점의 경도: λ₀
```
> 🔍 **이미지 검색어**: `longitude prime meridian` or `geographic coordinates system` or `meridians longitude lines`
- 원점이 **동서 방향 어디**에 있는가
- 본초자오선으로부터의 각도
- **측지원점 정의에 필수!**

**d. 원점의 위도 (Latitude)**
```bash
    북극 90°N
      |
    ━━━━━━━━━━ 위도 φ₀
      📍
    ━━━━━━━━━━ 적도 0°
```
> 🔍 **이미지 검색어**: `latitude lines equator` or `parallels of latitude` or `geographic coordinates latitude`
- 원점이 **남북 방향 어디**에 있는가
- 적도로부터의 각도
- **측지원점 정의에 필수!**

**e. 원점의 높이 (Ellipsoidal Height)**
```bash
      📍 측지원점
      ↕ h₀ (타원체고)
━━━━━━━━━━━━━━━━ 타원체면
```
> 🔍 **이미지 검색어**: `ellipsoidal height` or `geodetic height` or `height above ellipsoid`
- 원점이 타원체면으로부터 얼마나 높은가
- **측지원점 정의에 필수!**

#### 3️⃣ 방향 요소 (좌표축의 방향)

**f. 원방위각 (Initial Azimuth)** 🔴
```bash
         북 (0°)
          ↑
          |
    서 ←──📍──→ 동
      원점 |
          ↓
      기준 방향선
          ↘
         다른 측량점
         
원방위각 = 북쪽 → 기준선 각도
```
> 🔍 **이미지 검색어**: `azimuth bearing compass` or `geodetic azimuth` or `bearing angle true north`

**원방위각이란?**
- 측지원점에서 **다른 기준점을 향하는 방향**
- 진북(True North)을 기준(0°)으로 한 각도
- 예: 수원 원점 → 수리봉 방향 = 약 280°

**왜 필요한가?**
```bash
좌표축의 방향 정의
    ↓
X축 (동쪽), Y축 (북쪽)이 
지구 자전축과 정확히 일치하도록
    ↓
모든 측량의 방향 기준
```
> 🔍 **이미지 검색어**: `coordinate system axes` or `geodetic coordinates XYZ` or `cartesian coordinate axes`

- 좌표계의 **북쪽 방향**을 정의
- 각도 측정의 **기준선** 제공
- **측지원점 정의에 필수!**

#### 4️⃣ 지오이드 관련 (추가 요소)

**g. 지오이드 기복 (Geoid Undulation)**
```bash
  📍 지표면
   ↕ N (지오이드 기복)
━━━━━━━━━━━━━━━━ 지오이드면 (평균해수면)
   ↕ H (정표고)
━━━━━━━━━━━━━━━━ 타원체면
```
> 🔍 **이미지 검색어**: `geoid undulation` or `geoid ellipsoid separation` or `geoid height relationship`
- 타원체면과 지오이드면의 높이 차이
- 정밀 측량에서 필요
- **선택적 요소** (기본 정의에는 불필요할 수도 있음)

### 측지원점 정의 요소 정리표

| 요소 | 기호 | 역할 | 필수 여부 |
|------|------|------|----------|
| **타원체 장반경** | a | 지구 크기 (적도 반경) | ✅ **필수** |
| **편평률** | f | 지구 찌그러짐 정도 | ✅ **필수** |
| **원점의 경도** | λ₀ | 동서 위치 | ✅ **필수** |
| **원점의 위도** | φ₀ | 남북 위치 | ✅ **필수** |
| **원점의 높이** | h₀ | 수직 위치 | ✅ **필수** |
| **원방위각** | α₀ | 방향 기준 | ✅ **필수** |
| **지오이드 기복** | N₀ | 정밀 높이 변환 | ⚠️ 선택 |

## 3. 표준중력과 측지원점의 관계

### 표준중력이란?

**표준중력 (Standard Gravity)**
```bash
기호: g₀
값: 9.80665 m/s²

이것은 국제 표준값!
```
> 🔍 **이미지 검색어**: `standard gravity 9.8` or `gravitational acceleration` or `gravity constant`

**정의:**
- 해수면(또는 지오이드면)에서의 **평균 중력 가속도**
- 국제적으로 약속된 **표준값**
- 물리 계산, 단위 변환 등에 사용

### 표준중력의 용도

#### ✅ 표준중력이 사용되는 곳

**1) 중력 측량 (Gravity Survey)**
```bash
관측 중력값 vs 표준 중력값
       ↓
중력 이상(Anomaly) 계산
       ↓
지하 구조 파악
```
> 🔍 **이미지 검색어**: `gravity survey` or `gravity anomaly map` or `gravimetric survey`
- 지하 자원 탐사
- 지질 구조 연구
- 지오이드 모델 계산

**2) 물리 계산**
```bash
무게(Weight) = 질량(Mass) × 중력(g)

표준중력 g₀ 사용
```
> 🔍 **이미지 검색어**: `weight equals mass times gravity` or `W=mg formula` or `gravitational force`
- 무게 단위 변환 (kgf, N 등)
- 압력 계산
- 힘 계산

**3) 중력 보정**
- 정밀 측량에서 중력 영향 제거
- 지오이드 모델 보정
- GPS 높이 변환

#### ❌ 표준중력이 사용되지 않는 곳

**측지원점 정의** 🔴

```bash
측지원점 정의:
  ┌─────────────────┐
  │ 기하학적 요소    │ ← 타원체 (a, f)
  │ 위치 요소        │ ← 경도, 위도, 높이
  │ 방향 요소        │ ← 원방위각
  └─────────────────┘
       ↓
  ✅ 좌표계의 기준점
  ✅ 위치와 방향만 정의
  
표준중력:
  ┌─────────────────┐
  │ 물리적 상수      │ ← 중력 가속도
  │ g₀ = 9.80665   │
  └─────────────────┘
       ↓
  ❌ 위치와 무관
  ❌ 측지원점 정의에 불필요
```
> 🔍 **이미지 검색어**: `geodetic datum parameters` or `datum components` or `coordinate reference system`

### 왜 표준중력은 측지원점 정의에 불필요한가?

**1) 측지원점은 기하학적 개념**
```bash
측지원점 = 타원체 위의 한 점
         = 위치 (λ, φ, h)
         = 방향 (α)
         
중력 = 물리적 힘의 크기
     ≠ 위치의 개념
```
> 🔍 **이미지 검색어**: `geometric concept` or `coordinate system definition` or `spatial reference point`

**2) 좌표계와 중력은 독립적**
```bash
┌─────────────────────┐
│ 좌표계 (Coordinate) │
│ - 위치 표현         │
│ - 거리 측정         │
│ - 방향 정의         │
└─────────────────────┘
        ↕ 독립적
┌─────────────────────┐
│ 중력장 (Gravity)    │
│ - 물리적 힘         │
│ - 지구 인력         │
│ - 지오이드 관련     │
└─────────────────────┘
```
> 🔍 **이미지 검색어**: `coordinate system` or `gravity field earth` or `reference frame geodesy`

- 측지원점은 **좌표의 기준점** → 기하학
- 표준중력은 **힘의 표준값** → 물리학
- 둘은 **서로 독립적인 개념**!

**3) 역사적으로도 무관**
```bash
17세기: 좌표계 개발 (뉴턴 이전)
        ↓
18세기: 측지원점 설정
        ↓
20세기: 정밀 중력 측량 시작
```
> 🔍 **이미지 검색어**: `history of geodesy` or `geodesy timeline` or `surveying history`
- 측지원점은 중력 개념 없이도 정의 가능
- 단지 **타원체 + 위치 + 방향**만 있으면 됨

## 4. 측지원점 vs 중력 측량

### 개념 비교

| 항목 | 측지원점 | 중력 측량 |
|------|---------|----------|
| **목적** | 좌표계 기준 | 지하 구조 파악 |
| **측정값** | 위치 (λ, φ, h) | 중력 가속도 (g) |
| **사용** | 지도 제작, GPS | 자원 탐사, 지질 조사 |
| **단위** | 도(°), 미터(m) | mGal, m/s² |
| **필요 요소** | 타원체, 경위도, 방위각 | 중력계, 보정값 |
| **표준중력** | ❌ 불필요 | ✅ 필수 (비교 기준) |

### 둘의 관계

```bash
┌──────────────────────────────┐
│       측지원점               │
│   (좌표계의 기준)            │
│                              │
│  📍 (λ₀, φ₀, h₀, α₀)       │
│                              │
│  → GPS 측량                  │
│  → 지도 제작                 │
│  → 위치 결정                 │
└──────────────────────────────┘
            ↕
     좌표 제공 (보조적)
            ↕
┌──────────────────────────────┐
│       중력 측량              │
│   (지하 구조 파악)           │
│                              │
│  g(측정) vs g₀(표준)        │
│                              │
│  → 중력 이상 계산            │
│  → 지하 자원 탐사            │
│  → 지오이드 모델링           │
└──────────────────────────────┘
```
> 🔍 **이미지 검색어**: `geodetic survey` or `geodesy gravity relationship` or `geodetic measurements`

**관계:**
- 측지원점이 중력 측량 지점의 **좌표를 제공**
- 중력 측량 결과가 **지오이드 모델** 개선에 사용됨
- 하지만 **측지원점 정의 자체**에는 중력 불필요!

## 5. 실제 사례: 대한민국 측지원점

### 한국 측지원점의 역사

**구 측지계 (2002년 이전)**
```bash
타원체: Bessel 1841
장반경 a: 6,377,397.155 m
편평률 f: 1/299.1528128
원점 위치: 삼각원점 (서울 남산)
```
> 🔍 **이미지 검색어**: `Bessel ellipsoid` or `Tokyo datum` or `historical geodetic datum`

**신 측지계 (2002년 ~ 현재)**
```bash
타원체: GRS80 (≈ WGS84)
장반경 a: 6,378,137 m
편평률 f: 1/298.257222101
원점 위치: 국토지리정보원 (수원)
경도: 127° 03' 14.8779" E
위도:  37° 16' 33.3659" N
타원체고: 53.84 m
원방위각: 수원 → 영월 방향 약 280°
```
> 🔍 **이미지 검색어**: `GRS80 WGS84 ellipsoid` or `geodetic datum 2000` or `modern coordinate system`

**정의 요소:**
- ✅ 타원체 장반경: 6,378,137 m
- ✅ 편평률: 1/298.257222101
- ✅ 원점 경도: 127° 03' 14.8779" E
- ✅ 원점 위도: 37° 16' 33.3659" N
- ✅ 원점 높이: 53.84 m
- ✅ 원방위각: 정의됨
- ❌ **표준중력: 정의에 포함 안 됨!**

### 왜 표준중력이 없나?

```bash
질문: "한국 측지원점의 표준중력은?"

답: "측지원점 정의와 무관!"
     
이유:
1. 표준중력 = 전 세계 동일 (9.80665 m/s²)
2. 국가별로 다르지 않음
3. 측지원점 = 위치 정의 (중력과 독립적)
```
> 🔍 **이미지 검색어**: `standard gravity constant` or `g acceleration` or `9.8 m/s²`

## 6. 핵심 정리

### 측지원점 정의에 필요한 요소

```bash
✅ 필수 요소 (6가지)
├─ 1. 타원체 장반경 (a) ← 지구 크기
├─ 2. 타원체 편평률 (f) ← 찌그러짐
├─ 3. 원점의 경도 (λ₀) ← 동서 위치
├─ 4. 원점의 위도 (φ₀) ← 남북 위치
├─ 5. 원점의 높이 (h₀) ← 수직 위치
└─ 6. 원방위각 (α₀) ← 방향 기준

❌ 불필요한 요소
└─ 표준중력 (g₀) ← 물리적 상수, 위치 무관
```
> 🔍 **이미지 검색어**: `datum parameters` or `geodetic system elements` or `coordinate reference system`

### 암기 포인트 🔑

| 요소 | 측지원점 정의 | 이유 |
|------|-------------|------|
| **타원체 장반경** | ✅ 필수 | 지구 크기 정의 |
| **원점의 경도** | ✅ 필수 | 동서 위치 정의 |
| **원방위각** | ✅ 필수 | 방향 기준 정의 |
| **표준중력** | ❌ 불필요 | 물리적 상수, 위치와 무관 |

**핵심 개념:**
```bash
측지원점 = 기하학적 기준점
          (위치 + 방향 + 타원체)
          
표준중력 = 물리적 상수
          (중력 가속도의 표준값)
          
→ 둘은 독립적!
```
> 🔍 **이미지 검색어**: `geodetic datum concept` or `reference system` or `coordinate datum`

**시험 출제 포인트:**
- "측지원점 정의에 **불필요한** 것은?" → **표준중력** 🔴
- "측지원점에 **필요한** 것은?" → **타원체 장반경, 원점 경도, 원방위각** ✅

4. 원점의 경도

**정답**: 1번

**해설**:

측지원점은 **국가 측량의 기준이 되는 좌표계의 원점**으로, 다음 요소들로 정의됩니다:

**✅ 필수 요소들 (2, 3, 4번):**

- **2번 - 타원체의 장반경 (a)**: 
  - 지구를 타원체로 근사할 때의 **적도 반경**
  - WGS84: a = 6,378,137 m
  - 편평률과 함께 **타원체의 형상을 완전히 정의**
  - **측지원점 정의에 필수!** ✅

- **3번 - 원방위각 (Initial Azimuth)**:
  - 측지원점에서 다른 기준점을 향하는 **방향**
  - 진북을 기준(0°)으로 한 각도
  - **좌표축의 방향을 정의**하는데 필수
  - 예: 수원 측지원점 → 영월 방향
  - **측지원점 정의에 필수!** ✅

- **4번 - 원점의 경도 (λ₀)**:
  - 원점이 **동서 방향 어디**에 위치하는가
  - 본초자오선으로부터의 각도
  - 위도, 높이와 함께 **원점의 3차원 위치를 정의**
  - **측지원점 정의에 필수!** ✅

**❌ 불필요한 요소 (1번):**

- **1번 - 표준중력 (g₀ = 9.80665 m/s²)**:
  - 해수면에서의 **평균 중력 가속도** (물리적 상수)
  - 중력 측량에서 **관측값과 비교하는 기준**으로 사용
  - 지하 구조 탐사, 지오이드 모델링에 활용
  
  **하지만:**
  ```bash
  측지원점 = 좌표계의 기준 (기하학적 개념)
           = 위치 + 방향 + 타원체
           
  표준중력 = 물리적 힘의 크기
           ≠ 위치의 개념
           
  → 둘은 독립적!
  ```
  > 🔍 **이미지 검색어**: `coordinate system` or `geodetic framework` or `spatial reference`
  
  - 측지원점은 **위치와 방향만으로 정의** 가능
  - 중력은 측지원점 정의와 **무관한 물리량**
  - **측지원점 정의에 불필요!** ❌

**비유로 이해하기:**

```bash
집 주소를 정할 때:

✅ 필요:
  - 거리 이름 (원점의 경도/위도)
  - 번지수 (정확한 위치)
  - 건물 높이 (원점의 높이)
  - 정문 방향 (원방위각)
  - 지구 크기 (타원체)

❌ 불필요:
  - 그 위치의 중력값 (표준중력)
  
→ 주소 정의에 중력이 필요한가? No!
```
> 🔍 **이미지 검색어**: `coordinate address system` or `location reference` or `spatial addressing`

**답 정리:**

| 선택지 | 측지원점 정의 | 역할 |
|--------|-------------|------|
| 1. 표준중력 | ❌ **불필요** | 물리적 상수, 중력 측량용 |
| 2. 타원체 장반경 | ✅ 필수 | 지구 크기 정의 |
| 3. 원방위각 | ✅ 필수 | 방향 기준 정의 |
| 4. 원점의 경도 | ✅ 필수 | 동서 위치 정의 |

**따라서 답은 1번 - 표준중력입니다.** 🔴

**핵심 암기:**
- 측지원점 = **기하학** (위치 + 방향 + 타원체)
- 표준중력 = **물리학** (힘의 크기)
- **측지원점 정의에 중력 불필요!**
