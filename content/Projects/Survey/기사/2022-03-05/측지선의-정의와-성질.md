## 1. 측지선(Geodesic Line)이란?

### 측지선의 정의 🎯

**측지선**은 회전타원체(지구) 표면 위에서 **두 점 사이의 최단거리를 나타내는 곡선**입니다.

```bash
        A점 ●──────────● B점
              측지선
    ━━━━━━━━━━━━━━━━━━━━━
        회전타원체 표면
```

**원리**: 평면에서는 직선이 최단거리지만, 구면이나 타원체에서는 곡선이 최단거리입니다!

### 측지선과 다른 선들의 비교

#### 1️⃣ 측지선 vs 측선 vs 평균해면거리

```bash
┌─────────────────────────────────────────┐
│ 측지선 (Geodesic Line)                  │
│ - 회전타원체 위의 최단거리               │
│ - 이론적인 선                           │
│ - 직접 측정 불가능 ❌                   │
└─────────────────────────────────────────┘
         ↕️ 차이
┌─────────────────────────────────────────┐
│ 측선 (Survey Line)                      │
│ - 실제로 지표면에서 측정한 선           │
│ - 실측 거리                             │
│ - 직접 측정 가능 ✅                     │
└─────────────────────────────────────────┘
         ↕️ 차이
┌─────────────────────────────────────────┐
│ 평균해면거리 (Mean Sea Level Distance)  │
│ - 지오이드면 위의 거리                  │
│ - 측량 계산의 기준                      │
└─────────────────────────────────────────┘
```

#### 2️⃣ 거리의 종류

```bash
        A●          ●B  지표면 (관측)
          ╲        ╱
           ╲      ╱ ← 측선 (실제 측정)
            ╲    ╱
━━━━━━━━━━━━━━━━━━━━━ 타원체면
      ●────────●  ← 측지선 (이론)
      A'        B'
```

| 거리 종류 | 설명 | 측정 가능 여부 |
|---------|------|---------------|
| **측선거리** | 지표면에서 실측한 거리 | ✅ 가능 |
| **측지선거리** | 타원체면 위 최단거리 | ❌ 불가능 (계산) |
| **평균해면거리** | 지오이드면 위 거리 | ❌ 불가능 (계산) |

## 2. 측지선의 주요 성질

### 성질 1: 최단거리 경로

측지선은 회전타원체 표면에서 **두 점 사이의 최단 경로**입니다.

```bash
평면에서:
A ━━━━━━━━━ B  (직선 = 최단거리)

구면/타원체에서:
    A ●╱───╲● B  (대원의 호 = 최단거리)
     ╱  구면 ╲
    ───────────
```

### 성질 2: 수직절선과의 관계 (핵심! 🔴)

#### 수직절선(Normal Section)이란?

```bash
             수직선
              ↑
      측점 ●──┴── 
    ━━━━━━━━━━━━━━━ 타원체 표면
         ╱
        ╱ ← 타원체 중심 방향
```

**수직절선**: 측점에서 세운 **수직선을 포함하는 평면**이 타원체 표면과 만나는 곡선

#### 측지선과 수직절선의 각도 관계

```bash
        수직절선 A     수직절선 B
            ↑             ↑
            │  α₁    α₂  │
            │╱   ╲  ╱   ╲│
         A ●──────●──────● B
              측지선
    ━━━━━━━━━━━━━━━━━━━━━━━
         회전타원체 표면

핵심: α₁ = α₂ (각도를 1:1로 등분!)
```

**중요한 성질**: 
- 측지선은 양 끝 점에서의 **수직절선과 같은 각도**를 이룬다
- 즉, 두 수직절선 사이의 각을 **1:1로 등분**한다 (2:1 아님!)
- 이를 **측지선의 방위각 대칭성**이라고 한다

### 성질 3: 수직절선과의 교차 가능성

```bash
경우 1: 남-북 방향 (경도선을 따라)
     북 ●
         │  측지선 ≈ 경선
         │  → 수직절선과 거의 일치
     남 ●

경우 2: 동-서 방향 (위도선에 가까움)
서 ●～～～～～～● 동
   측지선이 곡선으로 휘어짐
   → 수직절선과 여러 번 교차 가능! ✅
```

**두 점이 거의 같은 위도 상에 있을 때**:
- 측지선은 곡선을 그리며 위아래로 진동
- 이 과정에서 수직절선들과 **여러 번 교차 가능**
- 특히 거리가 길수록 교차 횟수 증가

### 성질 4: 이중곡률 (Double Curvature)

#### 곡률의 종류

```bash
단일곡률 (Single Curvature):
━━━━╱────╲━━━━  ← 한 평면 내에서만 휘어짐
   (예: 원, 타원)

이중곡률 (Double Curvature):
    ╱───╲
   │  3D │  ← 여러 방향으로 동시에 휘어짐
    ╲___╱
   (예: 나선, 측지선)
```

**측지선의 곡률 특성**:
- 측지선은 **이중곡률(Double Curvature)**을 갖는다
- 즉, 한 평면에 놓이지 않고 **3차원적으로 휘어진다**
- 단일곡률이 아님! ❌

```bash
❌ 단일곡률 (틀림!)
    평면에 놓인 곡선
    ╱─────╲
   (원, 타원 등)

✅ 이중곡률 (정답!)
    3차원 공간의 곡선
      ╱─╲
     │   │  회전하며 휘어짐
      ╲─╱
```

### 성질 5: 직접 측정의 어려움

#### 왜 측지선을 직접 측정할 수 없는가? 🔍

```bash
┌─────────────────────────────────────┐
│ 측정 현장                           │
│                                     │
│   관측자                            │
│     👤                              │
│     │  어디가 측지선인지            │
│     ↓  알 수 없음!                 │
│   ●─────────● 지표면               │
│    A    ?    B                     │
└─────────────────────────────────────┘
         ↓ 문제점
┌─────────────────────────────────────┐
│ 1. 지표면 ≠ 타원체면               │
│    - 산, 건물, 계곡 등 장애물       │
│                                     │
│ 2. 타원체는 이론적 기준면          │
│    - 눈에 보이지 않음              │
│                                     │
│ 3. 측지선은 3차원 곡선             │
│    - 방향 설정이 매우 복잡         │
└─────────────────────────────────────┘
```

#### 실무에서의 해결 방법

```bash
1단계: 지표면에서 측선 거리 측정 (실측)
   A ●─────────● B
      d_측선

2단계: 보정 적용
   - 고도 보정
   - 해면 환산
   - 기타 보정

3단계: 측지선 거리 계산 (이론 계산)
━━━━━━━━━━━━━━━━━ 타원체면
   A'●─────────●B'
      d_측지선
```

**정리**:
- 측지선은 **계산으로만 구할 수 있다** (이론값)
- 현장에서는 **측선을 측정**하고, 이를 보정하여 측지선 거리를 구한다
- 따라서 "측지선은 직접 측정하기 어렵다"는 말이 **맞다** ✅

## 3. 측지선과 관련된 측량 계산

### 측지선 거리 계산 방법

#### 1️⃣ 단거리 (10km 이하)

```bash
평면삼각법 사용 가능
   A ●
      ╲  d
       ╲   
        ●B

d = √[(x₂-x₁)² + (y₂-y₁)²]
```

- 타원체를 평면으로 근사
- 오차가 작음

#### 2️⃣ 중거리 (10-50km)

```bash
타원체 계산 필요
━━━━━━━━━━━━━━━━
   A ●───────●B
      측지선

베셀(Bessel) 공식 사용
```

#### 3️⃣ 장거리 (50km 이상)

```bash
정밀 타원체 계산
━━━━━━━━━━━━━━━━━━━━
   A ●──────────────●B
      
빈센티(Vincenty) 공식 사용
- 반복 계산
- mm급 정확도
```

### 측지 계산의 두 가지 문제

#### 순문제 (Direct Problem)

**주어진 것**: A점의 좌표, 방위각, 거리
**구하는 것**: B점의 좌표

```bash
   A ●  방위각 α
      ╲ 거리 d
       ╲
        ●B (좌표 구하기)
```

#### 역문제 (Inverse Problem)

**주어진 것**: A점과 B점의 좌표
**구하는 것**: 방위각, 거리

```bash
   A ●
      ╲ 
       ╲ 방위각? 거리?
        ●B
```

### 응용 분야

```bash
→ 측지선 개념 필수
```

#### 3️⃣ 지적측량

```bash
경계점 간 거리 계산
●─────●─────●
  측지선 거리
  
정확한 면적 산정
```

#### 4️⃣ 해양/항공 측량

```bash

   대양 횡단 거리
   
최단 항로 결정
= 측지선 경로!
```

## 5. 핵심 요약

### 측지선의 주요 특징

```bash
┌─────────────────────────────────────┐
│ 측지선 = 타원체면 위 최단거리       │
├─────────────────────────────────────┤
│ ✅ 회전타원체 표면 위의 곡선        │
│ ✅ 두 점 사이의 최단 경로          │
│ ✅ 이중곡률 갖는 3차원 곡선        │
│ ✅ 직접 측정 불가능 (계산 필요)    │
│ ✅ 수직절선 각을 1:1로 등분        │
│ ✅ 같은 위도면에서 교차 가능       │
└─────────────────────────────────────┘
```

### 측지선 vs 수직절선

| 특징 | 측지선 | 수직절선 |
|-----|-------|---------|
| **정의** | 최단거리 곡선 | 수직면과 타원체의 교선 |
| **곡률** | 이중곡률 | 단일곡률 |
| **각도 관계** | 수직절선을 1:1로 등분 | - |
| **측정** | 불가능 (계산) | 불가능 (계산) |
| **실무 사용** | 정밀 거리 계산 | 국지 좌표계 |

### 암기 포인트

1. **측지선 = 최단거리** → 타원체 표면 위에서
2. **이중곡률** → 3차원 곡선 (단일곡률 아님!)
3. **직접 측정 불가** → 계산으로만 구함
4. **각도 등분 = 1:1** 🔴 → 2:1 아님! (시험 출제!)
5. **수직절선 교차 가능** → 같은 위도선 상에서
6. **실무**: 측선 측정 → 보정 → 측지선 환산

### 측지선 계산 공식 (참고)

**단거리 근사 (피타고라스)**:
```
d ≈ √[(x₂-x₁)² + (y₂-y₁)²]
```

**장거리 정밀 (빈센티)**:
```
반복 계산법 (수치해)
- a, b: 장반경, 단반경
- 위도, 경도 이용
- mm급 정확도
```

## 6. 실무 예시

### 예제: 서울-부산 측지선 거리 계산

**측정 조건:**
- A점 (서울): 북위 37.5°, 동경 127.0°
- B점 (부산): 북위 35.1°, 동경 129.0°

**계산 과정:**

```bash
1단계: 타원체 선택
   GRS80 (한국측지계 기준)
   a = 6,378,137m (장반경)
   f = 1/298.257 (편평률)

2단계: 빈센티 공식 적용
   반복 계산 (수렴)
   
3단계: 결과
   측지선 거리 ≈ 325.5 km
   방위각 ≈ 135° (남동쪽)
```

**비교:**
```bash
| 거리 종류 | 값 | 차이 |
|----------|-------|------|
| 직선거리 (직각좌표) | ~323 km | 기준 |
| 측지선 거리 (타원체) | ~325.5 km | +2.5 km |
| 실제 도로 거리 | ~400 km | +77 km |
```

## 연습 문제

**9. 측지선에 대한 설명으로 옳지 않은 것은?** (정답률:51%)
     
1. 두 점이 거의 같은 위도 상에 있을 경우에 측지선은 수직절선을 교차할 수도 있다.
2. 측지선은 두 수직절선 사이의 각을 2:1의 비율로 분할한다.
3. 측지선은 직접 측정하기 어렵다.
4. 측지선은 단일곡률을 갖는 곡선이다.

**정답**: 2번

**해설**:
- ❌ **2번이 틀렸습니다.** 측지선은 두 수직절선 사이의 각을 **1:1로 등분**합니다, 2:1이 아닙니다.
  - 측지선의 중요한 성질: **방위각 대칭성**
  - 양 끝 점에서 수직절선과 이루는 각도가 **같다** (α₁ = α₂)
  - 즉, 각을 **똑같이 나눈다** (1:1 등분)
  - 문제에서 "2:1의 비율"이라고 했으므로 **틀린 설명**

- ✅ **1번은 맞습니다.**
  - 두 점이 거의 같은 위도 상에 있으면 (동-서 방향)
  - 측지선이 곡선을 그리며 위아래로 진동
  - 이 과정에서 수직절선들과 **여러 번 교차 가능** ✅

- ✅ **3번은 맞습니다.**
  - 측지선은 회전타원체 위의 이론적 곡선
  - 현장에서는 타원체면이 보이지 않음
  - **직접 측정 불가능**, 계산으로만 구함 ✅

- ❌ **4번도 사실 틀렸습니다!** (함정 보기)
  - 측지선은 **단일곡률이 아님**
  - 측지선은 **이중곡률(Double Curvature)**을 갖는다
  - 3차원 공간에서 여러 방향으로 휘어지는 곡선
  - 그러나 문제에서 정답을 하나만 고르라면 **2번이 더 명확하게 틀림**

**종합 정리**:

```bash
┌─────────────────────────────────────┐
│ 측지선의 올바른 성질                │
├─────────────────────────────────────┤
│ ✅ 타원체면 위 최단거리             │
│ ✅ 이중곡률 갖는 3차원 곡선         │
│ ✅ 직접 측정 불가능                 │
│ ✅ 수직절선 각을 1:1로 등분 🔴     │
│ ✅ 같은 위도에서 수직절선 교차 가능 │
└─────────────────────────────────────┘
```

**핵심 암기:**
- **각도 등분 = 1:1** (2:1 아님!)
- **이중곡률** (단일곡률 아님!)
- **직접 측정 불가** (계산 필요!)

**보기별 평가**:

| 보기 | 내용 | 정오 | 비고 |
|-----|------|-----|------|
| 1번 | 수직절선 교차 가능 | ✅ 맞음 | 같은 위도선 상 |
| 2번 | 2:1 비율로 분할 | ❌ **틀림** | **1:1 등분이 정답** |
| 3번 | 직접 측정 어려움 | ✅ 맞음 | 계산으로만 구함 |
| 4번 | 단일곡률 | ❌ 틀림 | 이중곡률이 맞음 |

**정답 선택 이유**:
- 4번도 틀렸지만, 일부 교재에서는 "측지곡률" 관점에서 단일곡률로 보기도 함
- 하지만 2번의 "2:1 비율"은 **명백하게 틀린 내용**
- 따라서 가장 확실하게 틀린 것은 **2번**입니다
