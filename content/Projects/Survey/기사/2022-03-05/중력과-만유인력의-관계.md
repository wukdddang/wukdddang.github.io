## 1. 만유인력과 중력의 개념

### 1.1 만유인력 (Gravitational Force)이란?

**만유인력**은 뉴턴의 만유인력 법칙에 따라 **두 물체 사이에 작용하는 순수한 인력**입니다.

#### 뉴턴의 만유인력 법칙

```bash
F = G × (M × m) / r²

F: 만유인력 (N)
G: 만유인력 상수 (6.674 × 10⁻¹¹ N·m²/kg²)
M: 지구의 질량
m: 물체의 질량
r: 지구 중심으로부터의 거리
```

#### 특징

- **순수한 끌어당기는 힘**
- 지구 중심을 향함
- **지구 자전과 무관**
- 거리(r)에만 의존

```bash
   물체 m
     📦
      ↓ 만유인력 (F)
     🌍 지구
   (중심)
   
순수하게 질량에 의한 인력
```

### 1.2 중력 (Gravity)이란?

**중력**은 실제로 지구 표면에서 우리가 느끼는 힘으로, **만유인력과 원심력의 합력**입니다.

```bash
중력 (g) = 만유인력 (F) + 원심력 (Fc)
```

#### 원심력의 영향

지구가 자전하므로, 지표면의 물체는 **원심력**을 받습니다.

```bash
        자전축
         |
    극 ●━━●━━● 극
        \ | /
         \|/      ← 적도: 원심력 최대
        적도
        
원심력 (Fc) = m × ω² × r_e

ω: 지구 자전 각속도
r_e: 자전축으로부터의 거리 (적도에서 최대)
```

#### 위치별 원심력 크기

```bash
위치        자전축까지 거리    원심력
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
적도 (0°)      최대 (R)      최대
북위 45°       중간 (R/√2)   중간
극 (90°)       0             0
```

### 1.3 만유인력과 중력의 차이

#### 벡터 분석

**적도에서:**
```bash
      물체 📦
         ↓ 만유인력 (F)
    ━━━━━━━━━━━━━ 적도
         ↑ 원심력 (Fc)
        🌍
        
중력 (g) = 만유인력 (F) - 원심력 (Fc)
        
결과: 중력 < 만유인력
```

**극에서:**
```bash
      물체 📦
         ↓ 만유인력 (F)
    ━━━━━━━━━━━━━ 극
    원심력 = 0 (자전축 위)
        🌍
        
중력 (g) = 만유인력 (F) - 0
        = 만유인력 (F)
        
결과: 중력 = 만유인력 ✓
```

**중위도에서 (예: 북위 45°):**
```bash
      물체 📦
       ↙ ↓  
      /  ↓ 만유인력 (F)
     /   ↓
    45° ━━━━━━━━━
    ↗     (원심력 Fc, 옆으로)
        🌍
        
중력 (g) = 만유인력 (F)와 원심력 (Fc)의 벡터 합
        
원심력이 비스듬히 작용
결과: 중력 < 만유인력
```

### 1.4 정량적 비교

#### 위도별 중력과 만유인력 관계

```bash
위치         원심력    중력과 만유인력의 관계
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
극 (90°)      0       g = F (같음!) ✓
북위 45°    중간      g < F (다름)
적도 (0°)   최대      g < F (다름)
```

#### 구체적인 수치

```bash
위치           만유인력 (F)    원심력 (Fc)    중력 (g)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
극            9.832 m/s²     0 m/s²         9.832 m/s²
북위 45°      9.806 m/s²     0.017 m/s²     ~9.79 m/s²
적도          9.789 m/s²     0.034 m/s²     9.780 m/s²

극과 적도의 차이: 약 0.052 m/s² (약 0.5%)
```

### 1.5 왜 극에서만 같은가?

#### 핵심 이유 3가지

**1️⃣ 원심력이 0이다**
```bash
극은 자전축 위에 있음
↓
자전축까지의 거리 (r_e) = 0
↓
원심력 = m × ω² × r_e = m × ω² × 0 = 0
↓
중력 = 만유인력 - 0 = 만유인력 ✓
```

**2️⃣ 만유인력만 작용한다**
```bash
      📦 물체
       ↓ 만유인력만!
    ━━━━━━━ 극
    (원심력 없음)
       🌍
```

**3️⃣ 수학적 증명**
```bash
중력: g = F - Fc
극에서: Fc = 0
따라서: g = F - 0 = F

결론: 극에서만 중력 = 만유인력
```

### 1.6 종합 정리

#### 개념 비교표

| 구분 | 만유인력 (F) | 중력 (g) |
|------|-------------|----------|
| **정의** | 순수한 인력 | 만유인력 + 원심력 |
| **방향** | 지구 중심 향함 | 약간 비스듬함 (중위도) |
| **자전 영향** | 없음 | 있음 |
| **위도 의존** | 거의 없음* | 큼 (극-적도 차이) |
| **크기** | 위치에 따라 거의 일정* | 극 > 중위도 > 적도 |

\* 지구가 완전한 구가 아니라 타원체이므로 약간의 차이는 있음

#### 위치별 정리

```bash
┌────────────────────────────────────────┐
│ 극 (북극/남극)                         │
│ - 원심력: 0                            │
│ - 중력 = 만유인력 ✓                    │
│ - 이론적으로 같은 유일한 지점!         │
└────────────────────────────────────────┘
         ↓
┌────────────────────────────────────────┐
│ 중위도 (예: 북위/남위 45°)             │
│ - 원심력: 중간                         │
│ - 중력 < 만유인력                      │
│ - 원심력이 비스듬히 작용               │
└────────────────────────────────────────┘
         ↓
┌────────────────────────────────────────┐
│ 적도                                    │
│ - 원심력: 최대                         │
│ - 중력 < 만유인력                      │
│ - 중력이 가장 약한 곳                  │
└────────────────────────────────────────┘
```

### 1.7 실생활 응용

#### 로켓 발사와 중력

**왜 적도에서 로켓을 발사하는가?**

```bash
적도에서 발사의 장점:
1. 중력이 가장 약함 → 연료 절약
2. 지구 자전 속도 최대 활용 → 초속 약 465m 보너스!
3. 발사 효율성 최대

예: 프랑스령 기아나 (북위 5°)
   미국 케이프커내버럴 (북위 28°)
```

#### 정밀 측량에서의 중요성

```bash
GPS 측량, 중력 측량 시:
- 중력값이 위도마다 다름
- 극: 9.832 m/s²
- 적도: 9.780 m/s²
- 위도보정 필수! (이전 문서 참조)
```

### 1.8 핵심 암기 포인트 🎯

```bash
┌──────────────────────────────────────┐
│ 이론적으로 중력 = 만유인력인 곳?     │
│                                      │
│        답: 극 (북극/남극)            │
│                                      │
│ 이유: 원심력 = 0                     │
│      중력 = 만유인력 - 0             │
│           = 만유인력                 │
└──────────────────────────────────────┘
```

**암기 팁:**
1. **극** = 자전**극** = 자전축 위 = 원심력 0
2. 적도 = 자전 반지름 최대 = 원심력 최대
3. 중위도 = 중간 상태

**공식 암기:**
```bash
중력 (g) = 만유인력 (F) - 원심력 (Fc)

극에서:   g = F - 0 = F  ✓ (같음!)
적도에서: g = F - Fc     (다름)
중위도:   g = F - Fc'    (다름)
```

## 연습문제

**5.	다음 중 이론적으로 중력과 만유인력이 같은 지점은?(정답률:66%)**
     
1. 적도
2. 북위 45°
3. 남위 45°
4. 북극

**정답**: 4번 (북극)

**해설**:

중력과 만유인력이 같으려면 **원심력이 0**이어야 합니다.

✅ **4번 (북극)이 정답인 이유:**
- 북극은 **지구 자전축 위**에 위치
- 자전축까지의 거리 (r) = 0
- **원심력 = m × ω² × r = 0**
- 따라서 **중력 = 만유인력 - 0 = 만유인력** ✓
- 남극도 마찬가지이지만, 선택지에 북극만 있음

❌ **1번 (적도)이 틀린 이유:**
- 적도는 자전축에서 **가장 멀리** 떨어진 곳
- 원심력이 **최대**
- 중력 = 만유인력 - 최대 원심력
- **중력 < 만유인력** (다름!)

❌ **2번 (북위 45°), 3번 (남위 45°)이 틀린 이유:**
- 중위도는 자전축에서 **중간 거리**
- 원심력이 **중간값**
- 중력 = 만유인력 - 중간 원심력
- **중력 < 만유인력** (다름!)

**핵심 정리:**

| 위치 | 원심력 | 중력 vs 만유인력 |
|------|--------|-----------------|
| **북극/남극** | **0** | **같음 ✓** |
| 북위/남위 45° | 중간 | 다름 (g < F) |
| 적도 | 최대 | 다름 (g < F) |

**그림으로 이해:**

```bash
    ● 극 (정답!)
    ↓ 만유인력만
    원심력 = 0
    ∴ g = F ✓
    
━━━━━━━━━━━━━━
    
      45°
    ↙ ↓  만유인력
   ↗   원심력 있음
       ∴ g ≠ F
       
━━━━━━━━━━━━━━
    
    적도
    ↓ 만유인력
    ↑ 원심력 최대
    ∴ g ≠ F (차이 최대)
```

**시험 포인트:**
- 이 문제는 **개념 이해**를 묻는 문제
- "이론적으로"라는 표현 주목 → 순수 물리학적 관점
- 극 = 원심력 0 = 유일하게 g = F 인 지점
