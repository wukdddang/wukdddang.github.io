## 1. 방위각의 종류와 개념

### 방위각(Azimuth)이란? 🧭

**방위각**은 어떤 기준 방향으로부터 목표 방향까지 **시계방향**으로 측정한 수평각입니다.

```bash
        북 (0°)
         │
         │
서 ──────┼────── 동
(270°)   │   (90°)
         │
        남 (180°)
```

🔍 **이미지 검색 키워드**: `azimuth compass cardinal directions`, `azimuth angle diagram`, `compass rose degrees`

### 방위각의 기준에 따른 분류

측량에서는 **"북"을 기준**으로 어떤 북을 사용하느냐에 따라 방위각이 달라집니다!

#### 1️⃣ 진북방위각 (True Azimuth)

**진북(True North)**을 기준으로 한 방위각

```bash
진북 (지리학적 북극)
 ↑
 │ 진북방위각
 │    ↗️
 └────────→ 목표점
```

🔍 **이미지 검색 키워드**: `true north azimuth diagram`, `geographic north azimuth`, `true bearing angle`

**특징:**
- 기호: **T** (True)
- 기준: 지구의 자전축이 지표면과 만나는 점 (지리학적 북극)
- 고정됨: 시간이나 장소가 바뀌어도 일정
- 용도: **정밀 측량, 지도 제작**
- 측정 방법: GPS, 천문 관측, 자이로스코프

🔍 **이미지 검색 키워드**: `GPS true north`, `astronomical azimuth determination`, `gyrocompass true north`, `theodolite azimuth measurement`

#### 2️⃣ 자북방위각 (Magnetic Azimuth)

**자북(Magnetic North)**을 기준으로 한 방위각

```bash
자북 (자기 북극)
 ↑
 │ 자북방위각
 │    ↗️
 └────────→ 목표점
```

🔍 **이미지 검색 키워드**: `magnetic north azimuth`, `magnetic bearing compass`, `magnetic azimuth diagram`

**특징:**
- 기호: **M** (Magnetic)
- 기준: 나침반이 가리키는 북쪽 (지구 자기장의 북극)
- 변함: 시간과 장소에 따라 변화
- 용도: **현장 측량, 항해, 등산**
- 측정 방법: 나침반 (자기 컴퍼스)

🔍 **이미지 검색 키워드**: `compass azimuth measurement`, `magnetic compass surveying`, `brunton compass`, `prismatic compass azimuth`

#### 3️⃣ 도북방위각 (Grid Azimuth)

**도북(Grid North)**을 기준으로 한 방위각

```bash
도북 (지도상 북쪽선)
 ↑
 │ 도북방위각
 │    ↗️
 └────────→ 목표점
```

🔍 **이미지 검색 키워드**: `grid north azimuth`, `grid bearing map`, `UTM grid north`

**특징:**
- 기호: **G** (Grid)
- 기준: 지도 좌표계의 Y축 방향
- 용도: **지도상 계산, 군사 작전**
- 투영 왜곡: 지도 투영에 의한 왜곡 포함

### 세 가지 북의 관계

실제로는 세 가지 "북"이 **서로 다른 방향**을 가리킵니다!

```bash
      진북
       ↑
      /│\
     / │ \
    /  │  \
   /   │   \
  ↑    │    ↑
 자북  │   도북
       │
     측정점 📍
```

🔍 **이미지 검색 키워드**: `three norths diagram`, `true magnetic grid north`, `declination convergence diagram`, `three north relationship`

**한국 서울 기준 (대략적)**
- 진북 ↔ 자북: 약 **7°~8° W** (서편)
- 진북 ↔ 도북: 약 **0°~1°** (투영에 따라 다름)

## 2. 자침편차 (Magnetic Declination)

### 자침편차란? 🧲

**자침편차**는 **진북 방향과 자북 방향의 차이**를 나타내는 각도입니다.

```bash
      진북
       ↑
       │\
       │ \ 자침편차 (δ)
       │  \
       │   ↑
       │  자북
       │
     측정점 📍
```

🔍 **이미지 검색 키워드**: `magnetic declination diagram`, `declination angle true magnetic north`, `compass declination illustration`

### 자침편차의 표기

#### 서편 (Western Declination) - W

자북이 진북의 **서쪽**에 있는 경우

```bash
  자북    진북
   ↑       ↑
    \      │
     \     │
    5°W    │
       \   │
        \  │
      측정점 📍
```

🔍 **이미지 검색 키워드**: `west declination diagram`, `western magnetic declination`, `declination west negative`

- 표기: **5°W** 또는 **-5°**
- 의미: 나침반이 진북보다 5° 서쪽을 가리킴
- 지역: **한국, 일본, 중국 동부**

#### 동편 (Eastern Declination) - E

자북이 진북의 **동쪽**에 있는 경우

```bash
    진북    자북
     ↑       ↑
     │      /
     │     /
     │   5°E
     │   /
     │  /
      측정점 📍
```

🔍 **이미지 검색 키워드**: `east declination diagram`, `eastern magnetic declination`, `declination east positive`

- 표기: **5°E** 또는 **+5°**
- 의미: 나침반이 진북보다 5° 동쪽을 가리킴
- 지역: **북미 서부, 유럽 서부**

### 자침편차의 원인

**1) 지구 자기장의 북극 ≠ 지리학적 북극**

```bash
       지리학적 북극 (진북)
            ⭐
           /
          /
         / 약 11°차이
        /
       /
      🧲 자기 북극 (자북)
         (캐나다 북부)
```

🔍 **이미지 검색 키워드**: `geographic magnetic north pole difference`, `magnetic pole location Canada`, `geomagnetic pole shift`, `true vs magnetic north pole`

- 자기 북극: 현재 캐나다 북부 (위도 약 86°N)
- 매년 약 **40~60km씩 이동** 중

**2) 지각의 자성 물질**

```bash
측정점 📍
━━━━━━━━━━━━
████🔴████  ← 철광석, 자성암
████████████
```

🔍 **이미지 검색 키워드**: `local magnetic anomaly`, `magnetic minerals crustal`, `iron ore magnetic field`, `magnetic anomaly geology`

- 국지적인 자기 이상 발생
- 광산 지역, 화산암 지역에서 크게 나타남

### 자침편차의 변화

자침편차는 **시간과 장소**에 따라 변합니다!

#### 1️⃣ 장년변화 (Secular Variation)

```bash
서울의 자침편차 변화 (예시)

1900년: 5° W
1950년: 6° W
2000년: 7° W
2025년: 8° W ← 계속 변화 중!
```

🔍 **이미지 검색 키워드**: `secular variation magnetic declination`, `declination change over time`, `magnetic field drift`, `isogonic chart historical`

- 원인: 지구 내부 자기장 변화
- 주기: 수십~수백년
- 속도: 연간 약 **0.01°~0.05°**

#### 2️⃣ 일변화 (Diurnal Variation)

- 하루 중 변화: 약 **±0.1°**
- 원인: 태양풍과 전리층의 영향
- 정밀 측량에서는 고려해야 함

#### 3️⃣ 자기폭풍 (Magnetic Storm)

- 태양 활동 증가 시 급격한 변화
- 크기: 수도 ± 수° (극지방에서 심함)

### 자침편차 확인 방법

#### 1️⃣ 지형도에서 확인

```bash
┌────────────────────────────┐
│     1:25,000 지형도        │
│                            │
│  진북 ↑                    │
│      /                     │
│     / 7°30' W              │
│    ↑ 자북                  │
│   (2020년 기준)            │
└────────────────────────────┘
```

🔍 **이미지 검색 키워드**: `topographic map declination diagram`, `map declination indicator`, `USGS map declination`, `topographic map north arrows`

- 지형도 여백에 표시
- **발행 연도 확인 필수!**

#### 2️⃣ 온라인 계산

**NOAA (미국 해양대기청) 자침편차 계산기**
- 웹사이트: https://www.ngdc.noaa.gov/geomag/calculators
- 위도, 경도, 연도 입력 → 자침편차 계산

**한국 (서울 기준, 2025년)**
- 자침편차: 약 **7°~8° W**

🔍 **이미지 검색 키워드**: `world magnetic declination map`, `isogonic lines world map`, `NOAA magnetic declination`, `global declination chart`

#### 3️⃣ 현장 측정

**태양 관측법**
1. 정오에 태양 방향 측정 (진남)
2. 나침반으로 자남 측정
3. 두 방향의 차이 = 자침편차

## 3. 방위각 변환 공식

### 진북방위각 ↔ 자북방위각 변환

#### 공식 정리

```bash
┌────────────────────────────────────┐
│ 진북방위각 = 자북방위각 + 자침편차 │
└────────────────────────────────────┘

자침편차 부호:
- 서편(W): 음수 (-)
- 동편(E): 양수 (+)
```

#### 왜 서편이 음수인가? 🤔

**핵심 원리: 자북이 진북의 서쪽에 있으면, 자북방위각이 더 크다!**

**시각적 이해:**

```bash
[서편 5°W인 경우]

   자북    진북
    ↑       ↑
     \      │
      \     │
     5°W    │
        \   │         목표점
         \  │           ↗️
          \ │         /
        측정점 📍────

자북방위각: 94° (자북 기준으로 측정)
진북방위각: 89° (진북 기준으로 측정)

차이: 89° - 94° = -5° (서편)
```

🔍 **이미지 검색 키워드**: `west declination azimuth conversion`, `magnetic to true bearing west`, `declination correction west`, `azimuth conversion diagram`

- 자북이 진북보다 **5° 서쪽**에 있으므로
- 같은 목표점을 가리킬 때:
  - 자북 기준: 더 큰 각도 (94°)
  - 진북 기준: 더 작은 각도 (89°)
- 따라서: **진북방위각 = 자북방위각 + (-5°) = 자북방위각 - 5°**

```bash
[동편 5°E인 경우]

    진북    자북
     ↑       ↑
     │      /
     │     /
     │   5°E
     │   /          목표점
     │  /             ↗️
     │ /            /
        측정점 📍────

자북방위각: 85° (자북 기준으로 측정)
진북방위각: 90° (진북 기준으로 측정)

차이: 90° - 85° = +5° (동편)
```

🔍 **이미지 검색 키워드**: `east declination azimuth conversion`, `magnetic to true bearing east`, `declination correction east`, `positive declination diagram`

- 자북이 진북보다 **5° 동쪽**에 있으므로
- 같은 목표점을 가리킬 때:
  - 자북 기준: 더 작은 각도 (85°)
  - 진북 기준: 더 큰 각도 (90°)
- 따라서: **진북방위각 = 자북방위각 + 5°**

### 변환 예시

#### 예제 1: 서편(W) 지역

```bash
주어진 조건:
- 자북방위각: 120°30'
- 자침편차: 8°W

계산:
진북방위각 = 120°30' + (-8°) = 112°30'
```

#### 예제 2: 동편(E) 지역

```bash
주어진 조건:
- 자북방위각: 45°15'
- 자침편차: 10°E

계산:
진북방위각 = 45°15' + 10° = 55°15'
```

#### 예제 3: 역변환

```bash
주어진 조건:
- 진북방위각: 200°
- 자침편차: 5°W

계산:
자북방위각 = 진북방위각 - 자침편차
           = 200° - (-5°) = 205°
```

### 암기 방법 💡

```bash
┌────────────────────────────────────┐
│  서편(W) → 진북이 더 작다 → 빼기    │
│  동편(E) → 진북이 더 크다 → 더하기  │
└────────────────────────────────────┘

또는:

서(西)편 = 빼(-)기
동(東)편 = 더(+)하기
```

🔍 **이미지 검색 키워드**: `declination mnemonic`, `east is least west is best`, `declination memory trick`, `compass correction rule`
**참고**: 영어권에서는 "East is least, West is best"라는 표현이 있지만, 이는 나침반을 맞출 때의 표현이고, 실제 계산에서는 서편은 음수(-), 동편은 양수(+)입니다.

## 4. 실용 예시

### 등산 시 나침반 사용

**상황: 한라산 등산로에서 길을 잃음**

```bash
지도상 목표 방향: 진북방위각 75°
한국의 자침편차: 8°W

나침반에서 보아야 할 방향:
자북방위각 = 75° - (-8°) = 83°

→ 나침반을 83° 방향으로 따라가면 됨!
```

🔍 **이미지 검색 키워드**: `compass navigation declination`, `hiking compass declination adjustment`, `orienteering compass bearing`, `map and compass navigation`

### 측량 현장에서 방위각 보정

```bash
현장 측정 (나침반):
자북방위각 = 142°20'

측량 기록 (진북 기준 필요):
자침편차 = 7°30'W

보정:
진북방위각 = 142°20' + (-7°30') = 134°50'
```

### 고대 지도 복원

```bash
조선시대 지도 (1800년 제작)
표시된 방향: 자북방위각 30°

현재 (2025년):
1800년 자침편차: 약 5°W
2025년 자침편차: 약 8°W
변화량: 3°

진북방위각 (1800년) = 30° + (-5°) = 25°
```

## 5. 핵심 요약

### 방위각 종류

| 방위각 | 기준 | 기호 | 측정 도구 | 용도 |
|-------|------|------|----------|------|
| **진북방위각** | 지리학적 북극 | T | GPS, 천문 | 정밀 측량, 지도 |
| **자북방위각** | 자기 북극 | M | 나침반 | 현장 측량, 항해 |
| **도북방위각** | 지도 Y축 | G | 지도 | 지도상 계산 |

🔍 **이미지 검색 키워드**: `azimuth types comparison`, `true magnetic grid north table`, `bearing types surveying`, `north reference systems`

### 자침편차

```bash
┌──────────────────────────────────┐
│ 자침편차 = 진북 방향 - 자북 방향 │
└──────────────────────────────────┘

서편(W): 자북이 진북의 서쪽
동편(E): 자북이 진북의 동쪽
```

### 변환 공식

```bash
┌────────────────────────────────────┐
│ 진북방위각 = 자북방위각 + 자침편차 │
└────────────────────────────────────┘

자침편차 부호:
- W (서편): - (음수)
- E (동편): + (양수)
```

### 암기 포인트

1. **한국의 자침편차**: 약 **7~8°W** (서편)
2. **서편은 빼기**: 진북방위각 = 자북방위각 **- |W|**
3. **동편은 더하기**: 진북방위각 = 자북방위각 **+ E**
4. **자침편차는 변함**: 시간과 장소에 따라 변화 (장년변화)
5. **지형도 확인**: 발행 연도의 자침편차 확인 필수

1. 84°10'25"
2. 59°02'25"
3. 89°30'25"
4. 94°10'25"

```bash
- 자북방위각: 89°10'25"

- 구하는 것: 진북방위각
```

**STEP 1: 자침편차가 서편(W)임을 확인**

```bash
   자북    진북
    ↑       ↑
     \      │
      \     │
     5°W    │
        \   │         B점
         \  │          ↗️
          \ │        /
           📍 A점────
           
자북방위각: 89°10'25"
진북방위각: ?
```

### 원리 이해

**왜 서편일 때 빼는가?**

```bash
[시각적 설명]

   자북    진북
    ↑       ↑
     \      │
      \     │     같은 목표점(B)을 가리킬 때:
     5°\    │     
        \   │     - 자북 기준: 94° (더 큼)
         \  │     - 진북 기준: 89° (더 작음)
          \ │     
        A점 📍     차이 = -5° (서편)

자북이 서쪽에 있으므로:
자북을 기준으로 측정하면 각도가 크게 나옵니다.
진북을 기준으로 하려면 자침편차만큼 빼야 합니다!
```
