### **16주 완성! DApp 개발자 단기 집중 커리큘럼**

#### **Phase 1: DApp 개발 완벽 마스터 정복 (1주차 ~ 6주차)**

이 단계의 목표는 블록체인의 핵심 원리를 이해하고, Solidity와 React를 이용해 완전한 DApp 하나를 스스로 만들고 배포하는 것입니다.

- **1주차: 블록체인과의 첫 만남**
    
    - **목표:** 블록체인과 이더리움의 기본 개념 이해, 개발 환경(Remix)에 익숙해지기.
        
    - **학습 내용:** 강의 초반부 (DApp/블록체인 개요, 중앙화 vs 탈중앙화, Remix IDE 사용법).
        
    - **액션 아이템:** Remix IDE에서 간단한 변수 저장/호출 스마트 계약을 직접 작성하고 배포해보며 '트랜잭션'이 일어나는 과정을 체감하기.
        
- **2주차: Solidity 핵심 문법 마스터**
    
    - **목표:** 스마트 계약의 기본 구조와 Solidity 핵심 문법(변수, 함수, 제어자 등) 완전 정복.
        
    - **학습 내용:** Solidity 기초 문법 파트 (Pragma, 변수 타입, 함수, Public/Private 등).
        
    - **액션 아이템 (주말 과제):** 강의 예제 외에, 본인만의 간단한 계약(예: 간단한 투표 계약, 간단한 은행 입출금 계약)을 구상하고 코드로 구현해보기.
        
- **3-4주차: 실용적인 스마트 계약 구축 (ERC20 & DeFi)**
    
    - **목표:** DApp의 핵심 로직을 담은 스마트 계약 완성. 가장 중요한 ERC20 토큰 표준 이해.
        
    - **학습 내용:** 중반부 핵심 (생성자, 매핑, 배열, ERC20 토큰 만들기, 이자농사 개념).
        
    - **액션 아이템:** '나만의 OOO코인'을 만들어보고, 친구의 주소로 전송하는 트랜잭션을 일으켜보기. ERC20 표준 코드를 한 줄 한 줄 분석하며 각 함수(transfer, approve, transferFrom)의 역할을 완벽히 이해하기.
        
- **5-6주차: 프론트엔드 연동과 최종 배포**
    
    - **목표:** 스마트 계약을 React 프론트엔드와 연결하고, 실제 사용 가능한 DApp 완성하기.
        
    - **학습 내용:** 후반부 (Truffle, Ganache, Web3.js, React 연동, 최종 프로젝트 완성).
        
    - **액션 아이템:** 이 단계는 현재 웹 개발 역량을 발휘할 최고의 기회입니다. 강의와 똑같이 만들기보다, 부트스트랩 대신 다른 UI 라이브러리를 써보거나, 자신만의 UI/UX를 적용하여 프로젝트를 '내 것'으로 만들기. 완성 후 **반드시 Sepolia와 같은 공개 테스트넷에 배포**하고 링크를 포트폴리오로 남겨두기.

#### **Phase 2: NFT 마켓플레이스로 포트폴리오 강화 (7주차 ~ 14주차)**

이 단계의 목표는 RWA의 핵심인 NFT(ERC721) 표준을 깊게 이해하고, 두 번째 포트폴리오를 완성하여 기술적 깊이를 더하는 것입니다.

- **7-8주차: NFT 개념 및 ERC721 표준 정복**
    
    - **목표:** NFT의 기술적 정의와 ERC721 표준의 구조 이해.
        
    - **학습 내용:** `NFT 웹 개발 완벽 마스터` 강의의 초반부 (NFT 개념, ERC721 표준, EIP).
        
    - **액션 아이템:** OpenSea와 같은 NFT 마켓플레이스를 둘러보며, 특정 NFT의 'Contract Address', 'Token ID', 'Metadata'가 무엇을 의미하는지 직접 확인하고 강의 내용과 연결하기.
        
- **9-11주차: NFT 스마트 계약 개발 및 테스트**
    
    - **목표:** NFT 민팅(minting), 전송(transfer) 기능이 포함된 스마트 계약을 개발하고 테스트 코드 작성.
        
    - **학습 내용:** 강의 중반부 (NFT 스마트 계약 코딩, Truffle/Hardhat 환경 설정, Mocha/Chai 테스트).
        
    - **액션 아이템:** '나만의 NFT 컬렉션'을 기획해보기. 어떤 컨셉의 NFT를 만들고 싶은지, 어떤 속성(Properties)을 넣을지 구상하면 학습에 대한 동기부여가 훨씬 강해집니다.
        
- **12-14주차: 프론트엔드 구축 및 최종 완성**
    
    - **목표:** NFT 마켓플레이스의 프론트엔드를 완성하고, 두 번째 포트폴리오 프로젝트 마무리.
        
    - **학습 내용:** 강의 후반부 (React 프론트엔드 연동, Web3로 NFT 데이터 로딩 및 민팅 구현).
        
    - **액션 아이템:** 첫 번째 프로젝트와 마찬가지로, 자신만의 디자인과 기능을 추가하여 차별화하기. (예: 카테고리별 NFT 필터링 기능, 내가 민팅한 NFT 목록 보기 페이지 등).
