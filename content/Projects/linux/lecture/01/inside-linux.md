# Linux 시스템 내부 구조

## 커널 (Kernel)

- UNIX 시스템의 핵심입니다. 시스템 시작(부팅) 시에 로드됩니다. 메모리에 상주하는 제어 프로그램입니다.

- 시스템의 모든 자원을 관리하여 사용자와 다른 모든 사용자에게 일관된 시스템으로 제공합니다. 장치 관리, 프로세스 스케줄링 등과 같은 사용자 애플리케이션에 서비스를 제공합니다.

- 커널이 수행하는 기능의 예:
  - 시스템의 메모리를 관리하고 각 프로세스에 할당합니다.
  - CPU가 수행하는 작업을 스케줄링하여 각 사용자의 작업이 가능한 한 효율적으로 수행되도록 합니다.
  - 시스템의 한 부분에서 다른 부분으로 데이터 전송을 수행합니다.
  - 셸로부터의 명령어를 해석하고 실행합니다.
  - 파일 접근 권한을 강제합니다.

- UNIX 시스템을 사용하기 위해 커널에 대해 알 필요는 없습니다. 이러한 세부 사항들은 정보 제공 목적으로만 제공됩니다.

## 셸 (Shell)

- Unix 시스템에 로그인할 때마다 셸 프로그램에 배치됩니다. 셸의 프롬프트는 일반적으로 화면의 커서 위치에 표시됩니다. 작업을 수행하려면 이 프롬프트에서 명령어를 입력합니다.

- 셸은 명령어 해석기입니다. 각 명령어를 받아서 운영체제 커널에 전달하여 실행되도록 합니다. 그런 다음 이 작업의 결과를 화면에 표시합니다.

- 일반적으로 모든 UNIX 시스템에서 여러 셸을 사용할 수 있으며, 각각 고유한 장단점을 가지고 있습니다.

- 서로 다른 사용자가 서로 다른 셸을 사용할 수 있습니다. 처음에는 시스템 관리자가 기본 셸을 제공하며, 이는 재정의하거나 변경할 수 있습니다. 가장 일반적으로 사용 가능한 셸들은 다음과 같습니다:
  - Bourne shell (sh)
  - C shell (csh)
  - Korn shell (ksh)
  - TC Shell (tcsh)
  - Bourne Again Shell (bash)

- 각 셸에는 고유한 프로그래밍 언어도 포함되어 있습니다. "셸 스크립트"라고 불리는 명령어 파일들은 일련의 작업을 수행하는 데 사용됩니다.

## 유틸리티 (Utilities)

- UNIX는 수백 개의 유틸리티 프로그램을 제공하며, 이들은 종종 명령어라고 불립니다.

- 범용 기능들을 수행합니다:
  - 편집
  - 파일 관리
  - 인쇄
  - 정렬
  - 프로그래밍 지원
  - 온라인 정보 등

- 모듈형: 단일 기능들을 그룹화하여 더 복잡한 작업을 수행할 수 있습니다.
