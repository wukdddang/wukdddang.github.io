# 가상 메모리란 무엇인가?

리눅스는 가상 메모리를 지원합니다. 즉, 디스크를 RAM의 확장으로 사용하여 사용 가능한 메모리의 효과적인 크기가 그에 따라 증가합니다. 커널은 현재 사용되지 않는 메모리 블록의 내용을 하드 디스크에 기록하여 해당 메모리를 다른 목적으로 사용할 수 있게 합니다. 원래 내용이 다시 필요할 때는 메모리로 다시 읽어들입니다. 이 모든 과정은 사용자에게 완전히 투명하게 이루어집니다. 리눅스에서 실행되는 프로그램들은 단지 더 많은 양의 메모리가 사용 가능하다는 것만 보게 되며, 프로그램의 일부가 때때로 디스크에 위치한다는 것을 알아차리지 못합니다. 물론, 하드 디스크를 읽고 쓰는 것은 실제 메모리를 사용하는 것보다 느리므로(대략 천 배 정도 느림) 프로그램의 실행 속도는 떨어집니다. 가상 메모리로 사용되는 하드 디스크의 일부를 **스왑 공간**이라고 합니다.

## 스왑 공간의 구현 방법

리눅스는 스왑 공간으로 다음 두 가지 방법을 사용할 수 있습니다:

1. **파일시스템의 일반 파일**
2. **별도의 파티션**

스왑 파티션이 더 빠르지만, 스왑 파일의 크기를 변경하는 것이 더 쉽습니다(전체 하드 디스크를 다시 파티션할 필요가 없고, 모든 것을 처음부터 다시 설치할 필요도 없습니다). 필요한 스왑 공간의 크기를 알고 있다면 스왑 파티션을 사용해야 하지만, 확실하지 않다면 먼저 스왉 파일을 사용하여 시스템을 잠시 사용해보고 필요한 스왑 공간의 크기를 파악한 후, 크기에 대해 확신이 들 때 스왑 파티션을 만들 수 있습니다.

## 다중 스왑 공간 사용

리눅스에서는 여러 개의 스왑 파티션과/또는 스왑 파일을 동시에 사용할 수 있다는 점도 알아두어야 합니다. 이는 가끔씩만 비정상적으로 많은 양의 스왑 공간이 필요한 경우, 전체 공간을 항상 할당해두는 대신 그런 때에만 추가 스왑 파일을 설정할 수 있다는 의미입니다.

## 운영체제 용어에 대한 참고사항

운영체제 용어에 대한 참고사항: 컴퓨터 과학에서는 일반적으로 **스와핑**(전체 프로세스를 스왑 공간에 기록하는 것)과 **페이징**(보통 몇 킬로바이트의 고정된 크기 부분을 한 번에 기록하는 것)을 구분합니다. 페이징이 일반적으로 더 효율적이며, 리눅스도 페이징을 수행하지만, 전통적인 리눅스 용어에서는 어쨌든 스와핑이라고 부릅니다.
